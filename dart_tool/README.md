# Smriti

**Remember. Connect. Care.**

Smriti is an offline-first cognitive-care companion designed for people with cognitive difficulties and their caregivers in the North Eastern Region of India. This repository currently contains the redesigned Phase 1 foundation: pastel-blue accessible UI, onboarding, English/Hindi/Assamese selection, patient navigation, and connectivity-state architecture.

## Setup

1. Install the Flutter SDK and add `flutter/bin` to your PATH.
2. From this folder run `flutter pub get`.
3. Run on Android with `flutter run`.

Firebase is deliberately not required for the app to launch.
